# Misetanibox Mobile

Android-клиент на ядре [mihomo](https://github.com/MetaCubeX/mihomo). Добавил подписку — подключился. Без root.

**Скачать:** [files.geodema.network/misetani/Misetanibox_android.apk](https://files.geodema.network/misetani/Misetanibox_android.apk) · обновления приложение проверяет само (Настройки → Обновление).

## Что умеет

- **Подключение одной кнопкой** — TUN через `VpnService`, весь трафик устройства. Конфиг подписки запускается как есть, со всеми группами и правилами панели.
- **Сервера** — список стран из подписки, «Авто» (быстрейший), пинг по кнопке. Выбор применяется без переподключения.
- **Подписки** — несколько, переключение в один тап; форматы mihomo YAML, Xray JSON и список ссылок; свой User-Agent. Логотип, название, трафик и срок — из заголовков панели; кнопки «Продлить» и «Поддержка».
- **Офлайн-копия** — если панель недоступна (белые списки оператора, блокировка домена), туннель поднимается по последней сохранённой подписке; запасные адреса из `fallback-url`.
- **Роутинг приложений** — «мимо VPN» или «только VPN» для выбранных приложений (списки `VpnService`).
- **Режимы** — правила / глобально / прямой.
- **Цепочки** — трафик через несколько серверов подряд, WARP как выход (регистрируется сам).
- **Быстрый доступ** — плитка в шторке, виджет, автозапуск после перезагрузки.
- **Напоминание о продлении** — за несколько дней до конца подписки (`notification-subs-expire`).
- **Обложка** — свои обои на главном экране, навигация свайпом.
- **Экспертный режим** — селекторы групп подписки как в классических клиентах (Настройки → Селекторы групп).

## Заголовки панели

| Заголовок | Что делает |
| --- | --- |
| `profile-title`, `profile-logo` | название и логотип в списке подписок и шапке |
| `subscription-userinfo` | трафик и срок |
| `profile-web-page-url`, `support-url` | кнопки «Продлить» и «Поддержка» |
| `announce` | текст объявления под подпиской |
| `fallback-url` | запасные адреса подписки (через запятую; голый хост = тот же путь) |
| `notification-subs-expire` | `1`/`true` или число дней — напоминание об окончании |
| `ping-type`, `check-url-via-proxy` | способ пинга: `proxy`, `proxy-head`, `tcp`, `icmp` и URL проверки |
| `ping-result` | `icon` — точки вместо миллисекунд |
| `update-on-open` | перезапрашивать подписку при открытии приложения |

## Сборка

CI (`.github/workflows/android.yml`) на тег `vX.Y.Z` собирает подписанный APK. Ядро — gomobile-биндинг mihomo из `core/`, обязательные теги `-tags with_gvisor,cmfa`. Интерфейс — один файл `www/index.html` (Capacitor), нативная часть — `android/app/src/main/java/network/geodema/misetanibox/`.

Версия задаётся в трёх местах: `const BUILD` в `www/index.html`, `versionCode`/`versionName` в `android/app/build.gradle`, git-тег.

Патч-ноуты — в [CHANGELOG.md](CHANGELOG.md) и в Releases.
